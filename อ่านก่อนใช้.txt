ช่างถึก AI (Yotathai Chrome Agent) v2.5 — ชุดสำหรับเพื่อน
=========================================================
ส่วนขยาย Chrome แถบข้าง สั่งงานเป็นภาษาไทย ควบคุมเบราว์เซอร์ได้ (เปิดเว็บ คลิก พิมพ์ อ่านหน้าจอ)

ต้องมีก่อน: Google Chrome · Python 3 · ตัวช่วย AI ที่ใช้ได้ (เช่น คีย์ Gemini/OpenAI/Anthropic ของตัวเอง หรือโปรแกรม Antigravity)

ติดตั้ง (ทำครั้งเดียว)
1) แตกไฟล์ซิปไว้ที่ที่จำง่าย
2) Chrome → พิมพ์ chrome://extensions → เปิด "Developer mode" → กด "Load unpacked" → เลือกโฟลเดอร์ "extension"
3) ปักหมุดไอคอนช่างถึก AI ที่แถบบน
4) เปิดระบบเชื่อม: Mac ดับเบิลคลิก start_bridge_mac.command · Windows ดับเบิลคลิก start_bridge_windows.bat (เปิดทิ้งไว้ขณะใช้)
5) ให้ตัวเชื่อมใช้ AI ของคุณได้ ตั้งตัวแปรสภาพแวดล้อม ANTHROPIC_API_KEY หรือ GEMINI_API_KEY หรือ OPENAI_API_KEY ก่อนเปิดตัวเชื่อม (หรือติดตั้ง Claude Code แล้วล็อกอิน หรือเปิดโปรแกรม Antigravity ทิ้งไว้)
6) เปิดแถบข้าง (Ctrl+Shift+Y หรือ Command+Shift+Y)

ข้อควรระวัง
- ส่วนขยายอ่านและสั่งการทุกเว็บที่คุณเปิด (รวมถึงหน้าธนาคาร/อีเมล) ใช้ในโปรไฟล์ Chrome แยกสำหรับงานนี้จะปลอดภัยกว่า
- ห้ามเปิดโหมดตอบแชทอัตโนมัติกับบัญชีที่มีข้อมูลลูกค้า ถ้ายังไม่ได้ทดสอบ
- คีย์ AI ของคุณเก็บในเครื่องคุณเอง อย่าส่งให้ใคร
- ชุดนี้ไม่มีข้อมูลหรือความจำของผู้พัฒนา ความจำเริ่มต้นว่าง
- ผู้พัฒนา: โยธาไทย (yotathai.com) · ใช้ตามความรับผิดชอบของตนเอง ไม่มีการรับประกัน
