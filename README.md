## 🚀 วิธีติดตั้งง่ายที่สุด (3 ขั้นตอน)

1. **เปิดโปรแกรม Google Antigravity** ในคอมพิวเตอร์ แล้วล็อกอินด้วย **อีเมล Gmail ที่แจ้งไว้กับคุณช่างถึก**
2. **แตกไฟล์ ZIP** ที่ดาวน์โหลดมา แล้วเปิด Google Chrome พิมพ์ `chrome://extensions`
   - เปิดสวิตช์ **โหมดนักพัฒนาซอฟต์แวร์ (Developer mode)** มุมขวาบน
   - กดปุ่ม **โหลดส่วนขยายที่ยังไม่ได้แพ็ก (Load unpacked)** แล้วเลือกโฟลเดอร์ **`extension`**
3. **เปิดแถบด้านข้าง `Yotathai AI`** ใน Chrome แล้วกดปุ่มสีส้ม **🪟 ติดตั้งอัตโนมัติ (Windows)** หรือ **🍎 ติดตั้งอัตโนมัติ (Mac)** เพียงครั้งเดียว
   - ระบบจะตรวจสอบอีเมลใน Antigravity ของท่านอัตโนมัติ พร้อมโหลด **ฐานความรู้ราคากลางงานก่อสร้างราชการ ปี 2569 และการถอดแบบ (ปร.4 / BOQ)** เข้าสู่ AI ทันที!
